# Calibración del criterio

Casos reales que Alan aprobó o rechazó, cada uno con su porqué. Sirven como prueba de regresión: antes de mergear un cambio al criterio de un agente (ADR 0002), Tenoch corre el agente con al menos un caso relevante y compara el antes y el después.

## Reglas

- Cada caso registra el encargo exacto, lo que se entregó, el veredicto de Alan con sus palabras y lo que lo explica.
- Los casos no son precedente de estilo: muestran qué falló o qué funcionó, no qué copiar.
- Si un caso deja de representar el criterio de Alan, se marca como retirado. No se borra.
